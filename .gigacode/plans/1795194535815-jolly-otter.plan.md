# План рефакторинга UI: MVI + Voyager

## Обзор

Замена текущей навигации на `mutableStateOf` и кастомного `BaseViewModel<STATE, UI_STATE, ACTION, EFFECT>` на чистый MVI-шаблон с `BaseMviViewModel<INTENT, STATE, EFFECT>` и Voyager навигацией. Бизнес-логика Merger-фичи сохраняется полностью.

## Пошаговая реализация

### ШАГ 1: Базовая инфраструктура MVI

**1.1** Создать `MviIntent.kt`, `MviState.kt`, `MviEffect.kt` — пустые маркерные интерфейсы.

**1.2** Создать `BaseMviViewModel.kt`:
```kotlin
abstract class BaseMviViewModel<
    INTENT : MviIntent,
    STATE : MviState,
    EFFECT : MviEffect
>(initialState: STATE) : ViewModel() {
    private val _state = MutableStateFlow(initialState)
    val state: StateFlow<STATE> = _state

    private val _effect = MutableSharedFlow<EFFECT>(extraBufferCapacity = 1)
    val effect: SharedFlow<EFFECT> = _effect

    fun onIntent(intent: INTENT) { handleIntent(intent) }
    protected abstract fun handleIntent(intent: INTENT)
    protected fun setState(reducer: STATE.() -> STATE) {
        _state.update { currentState().reducer() }
    }
    protected fun currentState(): STATE = _state.value
    protected fun sendEffect(effect: EFFECT) {
        viewModelScope.launch { _effect.emit(effect) }
    }
}
```

**1.3** Создать `BaseRoute.kt`:
```kotlin
@Composable
fun <INTENT, STATE : MviState, EFFECT : MviEffect> BaseRoute(
    viewModel: BaseMviViewModel<INTENT, STATE, EFFECT>,
    onEffect: suspend (EFFECT) -> Unit,
    content: @Composable (state: STATE, onIntent: (INTENT) -> Unit) -> Unit
) {
    val state by viewModel.state.collectAsStateWithLifecycle()
    LaunchedEffect(viewModel) {
        viewModel.effect.collect { effect -> onEffect(effect) }
    }
    content(state) { intent -> viewModel.onIntent(intent) }
}
```

**Верификация:** `./gradlew composeApp:compileKotlinDesktop` — базовые файлы компилируются.

## Ключевые архитектурные решения

1. **Single State** — `MergerState` используется напрямую Compose UI, `MergerUiState` и `MergerConverter` удаляются
2. **Constructor Injection** — `MergerViewModel` получает зависимости через конструктор, Koin предоставляет через `get()`
3. **Effect → UI** — Effects используются только для сообщений (`ShowMessage`), навигация через State (FileDialog state)
4. **Tab Navigator** — 4 основных экрана через `TabNavigator`, без вложенной навигации (на будущее)
